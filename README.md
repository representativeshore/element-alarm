# element-alarm

Будильник на сообщения Element для macOS. Следит за Центром уведомлений и, как только
приходит уведомление Element, включает сирену и гудит, пока не тронешь само уведомление:
кликнешь, откроешь чат или смахнёшь. Просто открытое окно Element сирену не глушит.

## Как устроено

- `detect.py` читает базу Центра уведомлений (`usernoted/db2/db`) и печатает последний
  `rec_id` уведомления от Element. Ловит нативное приложение, PWA в Chrome и обычный Chrome,
  если в тексте есть element или matrix.
- `watch.sh` раз в четыре секунды спрашивает `detect.py`. На новом уведомлении переключает
  звук на динамики мака, ставит громкость на максимум и крутит системные звуки, пока запись
  не уйдёт из базы. Страховочный предел сирены тридцать минут.
- `off` выключает сторожа.

## Запуск

```
nohup ./watch.sh >watch.out 2>watch.err &
./off
```

Нужны `sqlite3`, `python3` и `SwitchAudioSource` (`brew install switchaudio-osx`).
Терминалу нужен Full Disk Access, иначе база уведомлений не читается.
Имя устройства вывода зашито в `watch.sh`, поменяй на своё.
Лог пишется в `alarm.log` рядом со скриптом.
